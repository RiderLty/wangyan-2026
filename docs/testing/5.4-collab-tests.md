## 过程记录（诚实原则）

- 调试期间发现并修复两个真实缺陷：① React StrictMode 下 useMemo 双调用泄漏 WebsocketProvider，
  产生"幽灵在线用户"（已改为 useEffect 管理会话生命周期）；② 修复前的泄漏连接 + 空 yjs 帧
  曾通过"空快照回写"清掉过一篇演示笔记正文（已据 5.3 测试记录重建，并新增 COLLAB-10 防误清保护）。
- 排障过程中曾怀疑"应用与 psql 看到不同数据库"，后确认是时序误读（两次读数之间发生了回写），
  数据库实例唯一（172.17.0.32:5432）。
