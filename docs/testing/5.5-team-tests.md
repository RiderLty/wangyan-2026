# 5.5 团队协作模块 功能测试用例表（论文 6.2.4 素材）

> 测试日期：2026-09-09　环境：macOS（node 22.22）+ NestJS :13000 + NAS PostgreSQL :15432
> 方法：curl 直打 API（双账号 RBAC 矩阵）+ Node WS 客户端 + 双 headless 浏览器（CDP 驱动）。
> 账号：demo@wangyan.test（团队创建者/owner）、lty@wangyan.test（被邀请方）。
