## 过程记录（诚实原则）

- 第一轮部署 web 容器崩溃循环：根因是 `git archive` 只导出已提交文件——nginx 模板化改造未提交，
  NAS 用旧配置构建。教训：上传构建前先 commit。已修复并重构建。
- 分包第一版用裸子串匹配 `'react'`，把 antd 内部 `reactNode.js` 等文件误分进 react 块，
  形成 react↔antd 循环 chunk，部署页运行时崩溃（React undefined）。改为带路径分隔符的精确匹配，
  本地 vite preview 验证无控制台错误后重新部署。
- 设计稿 13 表中 `attachments` 未建表：大纲无附件上传功能（范围约束），DDL 附录头部已注释说明，列入 7.3 改进。
