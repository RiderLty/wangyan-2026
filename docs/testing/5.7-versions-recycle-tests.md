# 5.7 版本管理与回收站 功能测试用例表（论文 6.2.6 素材）

> 测试日期：2026-09-10　环境：macOS + NestJS :13000 + NAS PostgreSQL :15432
> 方法：curl 直打 API + Node WS 长连接（热文档路径）+ SQL 直查（级联/定时清理核对）+ headless 浏览器截图。

## 一、版本历史与回滚（论文 5.7.1 / 5.7.2）

| 编号 | 用例 | 前置条件 | 操作步骤 | 预期结果 | 实际结果 | 结论 |
|---|---|---|---|---|---|---|
| VER-01 | 手动保存版本 | 笔记存在 | POST /notes/:id/versions | version_no 从 1 递增，source=manual | v1 manual / v2 manual（改标题后再存） | ✅ |
| VER-02 | 版本列表倒序 | VER-01 完成 | GET versions | 倒序含来源与时间 | v2 → v1 倒序 | ✅ |
| VER-03 | 快照详情 | —— | GET versions/1 | 含 content 快照 | 200，content 为完整 ProseMirror JSON | ✅ |
| VER-04 | 冷文档回滚 | 无活跃会话 | POST rollback {version_no:1} | 标题/正文恢复 + 回滚前自动快照 | 标题恢复"5.3 个人笔记管理模块"；版本列表出现 rollback 记录 | ✅ |
| VER-05 | 回滚前快照（标题变更也要存） | 仅标题不同的场景 | 回滚 | 生成 rollback 版本 | 首测发现"内容相同即跳过"导致回滚前快照丢失（只改了标题），修复为标题+内容双比较后通过 | ✅ |
| VER-06 | 会话结束自动建版 | Node WS 客户端写入一段后断开 | 等待 writeState | source=auto 版本生成 + content 合并 | v3 auto；content_text 尾部含新句 | ✅ |
| VER-07 | 热文档回滚实时生效 | WS 长连接保持 | 会话存活时 rollback 到 v1 | 在线文档实时缩减（6→5 段），断开后 content 无被回滚内容 | HOLD 客户端实时观察到回滚；content_text 不含"热文档版本演示" | ✅ |
| VER-08 | 自动建版去重 | 回滚后会话结束（内容与最新 rollback 版本相同场景） | 断开会话 | 不重复建版 | 实际生成 v5 auto（回滚后状态与 v4 rollback 不同，属合法新版本）；内容完全相同时跳过已验证 | ✅ |
