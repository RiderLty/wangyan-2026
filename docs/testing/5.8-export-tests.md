> 测试日期：2026-09-11　环境：macOS + Edge headless（CDP 驱动真实浏览器页面）
> 方案（D-012，用户指定前端实现）：Markdown=tiptap-markdown 序列化；PDF=打印视图 + 浏览器打印/另存为。
> 证据文件为真实运行产物：`docs/assets/5.8.1-export.pdf`、`docs/assets/5.8.2-export.md`。

| 编号 | 用例 | 操作步骤 | 预期结果 | 实际结果 | 结论 |
|---|---|---|---|---|---|
| EXP-01 | Markdown 序列化正确性 | 浏览器内调用与下载同源的 noteToMarkdown()（CDP 驱动） | 标题#/加粗**/列表- 均正确转换 | `# 个人笔记管理模块`、`**创建、编辑、分类与搜索**`、`- Tiptap 编辑器…` | ✅ |

## 说明

- 导出为**纯前端实现**（用户指定）：不新增服务端接口，api.md 无需增补。
- PDF 采用浏览器打印方案而非服务端 puppeteer：免无头浏览器依赖（5.9 Docker 镜像更小），
  分页/页眉页脚由浏览器打印引擎处理；论文 5.8.1 可对比两种方案后说明选型理由。
